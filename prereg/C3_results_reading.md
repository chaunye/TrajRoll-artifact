## 0. 一句话结论

- **E12 → H-C 档**：起作用的是**结构化记录本身**（act/target/err/n），**不是 world 内容，也不是「随便一个紧凑标记」**——
  无内容紧凑墓碑塌回基线（0/20），world 内容清空的安慰剂臂反而名义最高（**19/20** vs worldonly 12/20，p=0.020，过 ×2 Bonferroni）。
  五席评审 Persp W4 提出的 rival 解释（「随便一个紧凑尾部标记就够」）**被数据否掉**；论文「world fact carries」的归属**被推翻并照登**。
- **E13 → S-B 档**：temp 0.7 下 discard-only 部分逃逸（**8/20**）但仍比 ours（**16/20**）低 40 pp（p=0.0225），
  且与 b0（5/20）不可区分（p=0.50）→「丢弃单独不够」**在两个温度下都成立**，塌陷不是 temp-0 artifact。
- **E14 → V1 ✗ 照登 / V2 ✓ / V3 ✓**：臂间中位 TTFT 全挤在 26.1–27.0 ms（<1 ms，被 ~22 ms 固定开销淹没）→
  预注册的臂间排序预期**未复现**（如实照登）；但**逐轮 token↔时间桥很强**（合并 r=0.977 [0.974,0.980]，
  大重算臂斜率 0.049–0.054 ms/token，截距 ≈22 ms）；4 路并发共享下 TTFT ×1.6、观测排序保持。
  **评审最大的共识弱点（没有 serving 单位）由 V3 + V2 补上，且比预注册预期的形态更诚实。**

### 1.1 E13 门#3 FAIL 的排查与改判（L3 先例：判据侧，事后改判如实披露）

门#3 =「两个丢弃臂足迹接近 ≤15%」（抄自 A1A2 预注册 §4，**为 temp-0 批写**）。实测 ours 582.7 vs rollback 387.4（差 33.5%）。
按门纪律先查实现再解读，日志级证据：

- rollback@0.7 全 20 份日志 **0 条真墓碑行**（`grep "墓碑:"` = 0；首查误报 19 是「(rollback：丢弃整条，**无墓碑**…)」这行日志自带该词）；
- seed1 逐轮 prompt_tokens：**rollback 恒 290**（丢弃后回到检查点，模型反复重发同型调用，批内 dup=192），
  **ours 237→959 逐轮增长**（墓碑累积）→ 足迹差是「无墓碑累积 + 上下文每轮回检查点」的机械后果；
- 判定：**判据侧不适用于采样批**（temp-0 下两臂都冻结在同一上下文，足迹才接近），实现无 bug。与 L3 的 H4 处置同款。

### 1.2 两处与判读无关、但要留痕的实现发现

- `run_C3.sh` 的 `run()` 把 TTFT_SUMMARY 落到 `${sum%.txt}_ttft.txt`（= `e14_ttft_summary_ttft.txt`），
  而 e14seq 截断/统计的是 `e14_ttft.txt` → **误报「TTFT 0/60」**；数据本体在 ab_*_t0_s*.log（逐轮）与
  e14_ttft_summary_ttft.txt（run 级），**未丢、未补跑**。10-04 已修脚本（新哈希 `d99ad66b59015123`），
  并发批收集是写死同名所以本来就对。
- 逐轮 TTFT 行数 < run 级 n 合计（864 vs 1,094）：**差值 = 驳回轮 + 答案轮**（这两类轮在打印点之前

### 2.2 冻结主对比（Fisher 双边精确检验，本机复算）

| 对比 | 点差 | Fisher p | 判定 |
|---|---|---|---|
| **placebo vs worldonly** | **+35.0 pp** | **0.0197** | 显著（×2 Bonferroni 后 0.039 仍 <0.05），**方向 = placebo 更高** |
| **generic vs worldonly** | **−60.0 pp** | **<0.0001** | 显著，generic 塌到与 b0 不可区分（0/20 vs 0/20，p=1.0） |
| ours vs worldonly（次要） | +10.0 pp | 0.7411 | n.s.（与 L2 批 13 vs 12 同形） |
| placebo vs ours（次要） | +25.0 pp | 0.0915 | n.s. → 中间态报区间不站队 |

### 2.3 判据逐条（预注册 §1）

- **H-A（world 内容承载）✗**：placebo 不低于 worldonly，反而显著更高（+35pp，p=0.0197）——方向反了。**推翻。**
- **H-B（任何紧凑标记即可 = 评审的 rival）✗**：generic 与 worldonly 差 60pp（p<0.0001），且与 b0 完全同分布
  （0/20、全部触顶、dup 208）——**rival 解释被否掉**（这是对论文有利的方向）。
- **H-C（结构承载、内容不承载）✓ 成立**：generic(0) < placebo(19)，worldonly(12) ≈ placebo 之差落在
  H-C 的「world facts add nothing beyond」内（只是方向偏正）。论文措辞按预注册改写为
  **"the structured record (act/target/err) carries it; world facts add nothing beyond"**。

### 2.4 附带读出与两条诚实备注

- **dup 归属修正**：本批内字面重复跟踪的是**真实 world 内容的存在**（worldonly 158 vs placebo 34，
  两者 advice 都关）——不是 advice 的缺失。§5.3 原有「29→159 归因于 hint」的读法被本批证实是**混淆的**
  （worldonly 同时缺 advice、带 world）。论文里已同步修正归属。
- **跨批漂移实例**：ours 同配置在 E12 批 14/20、在 E14seq 批 8/20（temp 0 下 vLLM 数值非确定 +
  前缀缓存状态不同）——预注册「跨批不比」纪律的直接实证，§4.5 已有对应句子，判读不跨批。
- placebo 名义最高臂一事**如实写入论文**（19/20 vs ours 14/20，p=0.0915 n.s.），不隐藏。
- 机制性猜想（仅标注、不站队）：真实 world 里的具体路径可能诱导模型「盯着墓碑里的路径反复重试」，
  占位符反而逼出重新探索——与 placebo 轮数更少（13.3 vs 16.2）方向一致。**未单独检验，属假设。**

### 3.2 判据逐条（预注册 §2，全部批内比）

| 档 | 条件 | 实测 | 判定 |
|---|---|---|---|
| S-A | rollback ≤15% 且 ours−rollback ≥20pp（p<0.05） | rollback 40% >15% | **✗** |
| **S-B** | rollback 逃逸（>15%）但仍 < ours | 8/20 vs 16/20，**+40.0pp，p=0.0225** | **✓ 成立** |
| S-C | rollback ≈ ours | 40pp 差、p=0.0225 | ✗（2×2 没塌） |

- 次要：ours vs b0 = +55pp，**p=0.0012**（恢复效应本身在采样下存活，与 temp-0 批同数量级）；
  rollback vs b0 = +15pp，p=0.5006 **n.s.**——丢弃无墓碑在两个温度下都与基线不可区分。
- 结论措辞（预注册 S-B 指定）：**"discard alone is insufficient at both temperatures"**；
  §5.3/§8.4 的「decoding-specific」归因撤下，改为「sampling softens (8/20) but does not close (p=0.023) the gap」。
- 机制注：rollback@0.7 的 dup=192（≈9.6 次/run）——采样没有打破循环，上下文每轮回检查点、
  模型重抽出的仍是同型调用（seed1 逐轮 prompt 恒 290 token 的日志级证据，§1.1）。

## 4. E14 TTFT 微基准（阶段1 单流 3×20 --stream；阶段2 4 路并发共享缓存）

### 4.1 V1（冻结：三臂 TTFT 中位数排序 == 重算 prefill 排序）→ **✗ 照登**

| 臂 | 逐轮 TTFT 中位 | run 级 p50 中位 | 重算 prefill/run（每轮 ≈） |
|---|---|---|---|
| ours | **26.1 ms** | 26.6 | 1193（≈66/轮） |
| sysend | 27.0 ms | 27.8 | 2254（≈125/轮） |
| truncate-4 | 26.3 ms | 27.5 | 6039（≈325/轮） |

排序：TTFT `ours < truncate-4 < sysend` ≠ prefill `ours < sysend < truncate-4` → **✗**。
诚实解释（照登不辩解）：臂间差 <1 ms，被 ≈22 ms 的固定调度/解码首块开销淹没——5.1× 的重算差
（ours vs truncate-4 每 run 1193 vs 6039）在臂间中位数上只值 0.2 ms。**「重算排序 = 时间排序」的臂间版本不成立。**

### 4.2 V2（4 路并发：绝对值上升 + 排序保持）→ **✓**

| 臂 | 单流中位 | 4-way 中位 | 倍数 |
|---|---|---|---|
| ours | 26.1 | 41.7 | ×1.60 |
| sysend | 27.0 | 43.5 | ×1.61 |
| truncate-4 | 26.3 | 43.0 | ×1.64 |

三臂全部上升、4-way 排序与单流观测排序逐字相同 → **✓**（"ordering preserved under 4-way cache sharing"）。

### 4.3 V3（token↔时间桥）→ **✓，这是本实验的主产出**

| 范围 | n | r | 95% CI | 斜率 | 截距 |
|---|---|---|---|---|---|
| 合并 3 臂 | 864 | **0.977** | [0.974, 0.980] | 0.0526 ms/tok | 22.2 ms |
| 仅 ours | 325 | 0.224 | [0.118, 0.325] | 0.0199 | 25.2 ms |
| 仅 sysend | 292 | 0.888 | [0.861, 0.910] | 0.0490 | 21.7 ms |
| 仅 truncate-4 | 247 | 0.991 | [0.989, 0.993] | 0.0537 | 21.8 ms |

- 斜率取**有足够 x 范围的两臂**（sysend 0.049、truncate 0.054 ms/token）；ours 的 x 太窄（≈66 tok/轮）斜率噪声大（r=0.224）。
- 合并 r=0.977 部分由臂间散布贡献——论文里写「斜率 + 截距 + 合并 CI」三件套，不给单点主导的解读。
- **论文拿到的 serving 单位**：重算 token 的边际时延 ≈ **0.05 ms/token**，固定开销 ≈ **22 ms**——
  评审四席共同要求的「真实时间单位」有了实测标定。
- 选择性披露：逐轮对**不含答案轮与驳回轮**（§1.2，e5_loop 的打印点在这两类轮之前），
  n=864/1,094；两类轮的 TTFT 分布没有理由系统性偏移，但已如实记录。
